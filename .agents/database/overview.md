# Database Overview

## Findings

ไม่พบข้อมูล database ใน repository นี้: ไม่มี schema, migration, seed, ORM, SQL, database driver, model repository หรือ server-side persistence implementation.

The UI consumes remote API data for projects, participants, sponsors, shirt sizes, limits, and tracking. Those records may be backed by a database in the external backend, but that cannot be established from this codebase.

## Do Not Infer

- Database vendor and tables: ไม่พบข้อมูล
- Relationships and constraints: ไม่พบข้อมูล
- Retention, deletion, audit, and transaction rules: ไม่พบข้อมูล
- Source of truth for payment or shipment status: external backend behavior is undocumented here
